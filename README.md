# KupoCombo

KupoCombo is a work-in-progress Dalamud training tool for practising FFXIV openers, rotations, priorities, and recovery at a training dummy.

It is intentionally a teaching aid, not a live encounter assistant or combat automation tool.

The current Machinist profile uses an Icy Veins 7.55 baseline: a fixed opening tool spine, potency-aware Reassemble use, an exact eight-second Hypercharge safety gate, charge preparation, and one-weave short-GCD windows.
